농장 데이터를 기록하지 않는다.

## 시작 전 확인

- [ ] 실제 장치와 생산 계정을 사용하지 않았다.
- [ ] 새 세션 DB를 사용했다.
- [ ] 온라인, 두 구역, 네 지표, 활성 저수위 알람이 보인다.
- [ ] 구역별 수위/알람 근거, 5초 장치 로컬 종료와 물리 안전 미검증
  안내, 적용 전 확인이 보이고 확인 전에는 적용 버튼이 비활성이다.
- [ ] `즉시 정지 (소프트웨어)`와 물리 비상정지/인터록 비대체 안내가
  제어 화면에 함께 보인다.
- [ ] 참가자에게 정답 구역이나 메뉴 위치를 설명하지 않았다.
- [ ] 녹화 여부와 익명 기록 범위를 안내했다.

비식별 스크린샷 또는 로그가 있으면 `artifacts/usability/S__/` 아래의 상대
경로만 적는다. 원본에 개인 정보가 포함되면 첨부하지 않는다.

세션 종료 후에는 아래 기록기로 관찰표의 표준 지표만 입력한다.

```bash
npm run usability:record -- S01
```

기록기는 `artifacts/usability/S01-result.json`을 만들며 기존 결과를 덮어쓰지
않는다. [session-result.example.json](./session-result.example.json)은 wire 예시와
수동 복구용으로만 사용한다. 원문 답변, 이름, 연락처, 농장명은 JSON에 추가하지
않는다.
