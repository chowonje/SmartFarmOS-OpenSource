# 2026 오픈소스 개발자대회 공식 제출 요구사항

확인일: 2026-08-24
범위: 대회 홈페이지의 2026-08-06 출품작 제출 가이드, 공식 결과보고서
양식, 운영규정, OSS 포털과 NIPA 공고. 이 문서는 운영사무국의 개별 답변을
대체하지 않는다.

## 제출 마감과 완료 조건

- 마감은 `2026-08-27(목) 18:00 KST`다.
- 대회 홈페이지에서 `접수 및 조회 → 출품작 제출 → 제출하기 → 파일 업로드
  → 출품작 제출 완료하기` 순서로 진행한다.
- 화면 상태가 `제출 완료`인지 확인하고 제출완료 안내 이메일도 받아야 한다.
- 마감 전 마지막으로 완료한 제출본이 평가 대상이며, 소스는 각 평가 시점의
  공개 저장소 상태를 기준으로 검증된다.

## ZIP 업로드 구성

다음 파일을 한 ZIP에 넣는다.

1. 공식 결과보고서 원본 1개: `HWP/HWPX` 또는 `DOC/DOCX`
2. 위 원본과 내용이 같은 PDF 1개
3. 다른 공모전·정부지원 등의 중복수혜에 해당할 때만 공식 중복수혜 확인서

결과보고서 안내 페이지는 삭제하고, 회색 가이드 문구도 모두 삭제한다.
용지 여백은 변경하지 않으며 본문은 맑은 고딕 10pt, 5페이지 이내다.
붙임 1 SBOM과 해당 시 붙임 2 AI 명세는 본문 분량 제한과 별개다.

권장 최종 파일명은 공식 예시에 맞춰 아래처럼 동일한 기본 이름을 쓴다.

```text
2026 오픈소스 개발자대회 결과보고서_접수번호(팀명).docx
2026 오픈소스 개발자대회 결과보고서_접수번호(팀명).pdf
```

ZIP 파일명과 용량 제한은 공개 가이드에서 확인하지 못했다. 제출 화면의
실제 제한을 업로드 직전에 확인한다.

## 보고서에 기재할 공개 산출물

- 전체 소스는 심사와 검증이 가능한 상태로 GitHub, Hugging Face 같은 공개
  저장소에 게시한다.
- 결과보고서에는 대표 공개 저장소 URL 1개만 기재한다. 추가 저장소, 배포 앱,
  문서와 기타 산출물은 대표 저장소에서 연결한다.
- 시연영상은 3분 이내로 YouTube에 게시하고 URL만 기재한다. 영상 파일은 ZIP에
  넣지 않는다.
- 별도 산출물 파일은 추가 업로드하지 않고 결과보고서나 대표 저장소에 포함한다.
- 우수·수상팀은 수상일부터 5년 동안 공개 저장소를 Public으로 유지해야 한다.

## 라이선스, SBOM, AI

- 참가자가 직접 작성한 코드는 OSI 승인 오픈소스 라이선스를 적용해야 한다.
- 라이브러리, 프레임워크, 모델, 데이터와 기타 제3자 저작물은 출처와
  라이선스를 공개하고 실제 재배포 권리를 확인한다.
- 붙임 1 SBOM은 필수다. 각 항목에 이름, 버전, 라이선스, 공식 저장소 URL,
  사용 목적과 주요 기능을 기재한다.
- 프로젝트에 AI 모델을 탑재·적용했다면 붙임 2를 제출한다. 기반 모델,
  데이터셋, 가중치 공개와 라이선스 조건을 해당 개발 유형에 맞게 작성한다.
- 2026-07-28 공식 Q&A는 상용 AI를 코드 작성·디버깅 보조로 사용하는 것을
  허용하고, 제품에 탑재·적용되는 AI 모델 제한과 구분한다. SmartFarmOS에는
  AI 모델이 없으므로 모델 유형 1~3을 선택하지 않는다. 최신 제출 가이드의
  지시에 따라 붙임 2는 삭제하고, 공식 양식에 별도 보조도구 사용란이 있으면
  실제 코딩 보조 범위만 사실대로 적는다.

## 공식 심사 배점

1차 서면 평가 30점은 프로젝트 구조·코드 완성도, 오픈소스 발전 가능성,
개발 문서 구체성, 혁신성, 협업·관리체계를 각 6점으로 평가한다.

2차 평가 70점은 작품발표 10점, 활용성 15점, 데모 완성도 10점, 커뮤니티
확장 가능성 5점, 오픈소스SW 적절성 15점, 기능테스트 10점, 라이선스 검증
5점이다. 실제 클라우드 데모는 공식 제출 파일의 독립 필수항목은 아니지만,
활용성·데모·기능테스트의 증거로 사용할 수 있다.

## 아직 확인할 항목

- 참가 접수번호, 팀명, 참가부문, 팀 인원과 과제유형
- ZIP 파일명과 업로드 용량 제한
- 평가 시점의 저장소 상태를 재현할 고정 commit/tag 표기 방식
- 모두의 AI 실험실 무상 클라우드 자원 사용이 중복수혜 확인 대상 공공지원에
  해당하는지

프로젝트 소유자는 2026-08-24 동일 성과의 중복수혜가 없다고 확인했다.
다만 승인된 무상 클라우드 자원은 현물성 공공지원으로 해석될 가능성을
운영사에 확인한다. 확인 전에는 기존 기록을 자동으로 바꾸거나 중복수혜
확인서를 임의로 추가하지 않는다.
