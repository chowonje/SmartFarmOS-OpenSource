# 2차 발표평가 자료 구성안

공식 자료는 2차 발표평가에 PPT 등이 필요함을 알리지만, 발표 시간·장표
수·서식은 현재 확정하지 못했다. 아래는 8장 기본안이며 1차 합격 후
사무국 안내에 맞게 조정한다.

1. **문제** — 다구역 온실의 판단·제어·결과 근거가 흐트러진 문제
2. **사용자 흐름** — 주의 구역→원인→알람 확인→관수→ACK/감사
3. **구조** — PWA→API→SQLite와 simulator→Edge→API 경계
4. **안전·정합성** — Edge 자격의 exact farm/device scope, 만료, 멱등성,
   accepted telemetry, 재배주기/농장 공통 audit, 완료 ACK의 Edge 저장·재시작
   재전송과 불명확 실행 no-replay
5. **실제 시연** — 2번 베드 저수위와 선택/반복 안전 가드
6. **오픈소스·신규성** — 기존 교육 성과와 새 계약·Edge·PWA·검증의 분리
7. **증거** — 제품 테스트 304개와 제출/도구 테스트 80개(총 384),
   외부 의존성 155개 라이선스 선언, schema 1~7에서 8로의 migration/restart,
   browser, 익명 사용성 결과
8. **정직한 한계와 파일럿** — 시뮬레이터 로컬 자동정지/ACK 복구와
   물리 인터록·실행 중 장치복구·MQTT·생산인증의 구분

## 발표 증거 규칙

- 수치는 최종 `npm run submission:rehearse` 보고서와 일치시킨다.
- 사용성 결과는 3–5명 작은 표본으로 표현하고 전체 농업인으로 일반화하지
  않는다.
- 시뮬레이터를 실장비로, HTTP Edge를 MQTT로, 확인 체크를 물리 인터록으로
  표현하지 않는다.
- Priva는 공개 제품 원칙 벤치마크이며 상표·UI·비공개 알고리즘을 복제했다고
  주장하지 않는다.
