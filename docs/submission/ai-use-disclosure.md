# AI 사용 고지 초안

릴리스 게이트: `PENDING_OWNER_CONFIRMATION`

공식 결과보고서 붙임 2는 제품에 AI 모델을 탑재·적용한 경우의 모델·가중치·
라이선스 명세와 상용 AI 보조도구 사용 범위를 함께 다룬다. SmartFarmOS에는
AI 모델을 탑재하지 않았으므로 유형 1~3은 선택하지 않는다. 다만 최신 제출
가이드는 해당 사항이 없으면 붙임 2를 삭제하라고 해, 코딩 보조 AI만 사용한
경우의 포함 여부는 사무국 서면 답변으로 확정한다. 이 문서는 투명한 고지를
위한 프로젝트 내부 초안이다.

## 공개할 핵심 내용

SmartFarmOS 개발에는 AI 코딩 에이전트가 사용되었다. AI는 아키텍처 비교,
계약·코드·테스트·문서 초안, 버그 조사, 브라우저 리허설, 리뷰에 보조적으로
활용되었다. AI 출력 그 자체를 성공 증거로 취급하지 않았고, 실행 가능한
결과는 로컬 계약 검증, 유형 검사, 단위·통합 테스트, SQLite 재시작, 실제
브라우저 흐름, 독립 리뷰와 리허설로 확인했다.

## 사람이 확정해야 하는 책임

- 제품 범위, 대회 주장, 사용자 검증 판정
- 기존 교육 프로젝트와 신규 개발분의 분리
- 재사용 권리, 오픈소스 라이선스, 외부 자료·자산 권리
- 자격증명 회전, 공개 여부, 최종 보고서·영상·발표 내용

## 데이터·보안 경계

- 정보 검색이 필요한 경우 공개된 공식 자료만 조사 대상으로 삼는다.
- 기존 저장소의 `.env`, 서비스 계정 파일, 실제 키 값은 새 저장소나
  외부 서비스로 복사하지 않는다.
- 사용성 기록은 `S01`과 같은 익명 코드와 비식별 집계만 제출 증거에
  사용한다.
